Control Principal del Sistema: El Kernel y los SO

El Sistema Operativo (SO) es el software base encargado de administrar el hardware del ordenador. El núcleo o Kernel representa el componente más crítico del SO, ejecutándose en el nivel de máxima prioridad del hardware (Anillo 0 o Modo Privilegiado), interactuando de forma directa con los registros del procesador y la memoria física.

El Kernel gestiona de forma centralizada la asignación de memoria a los programas (paginación y segmentación), la planificación e hilos de ejecución en los núcleos de la CPU (Scheduling), y el control de los sistemas de archivos. El software de aplicación de usuario jamás manipula el hardware directamente; se comunica obligatoriamente con el Kernel mediante llamadas al sistema controladas llamadas System Calls.
